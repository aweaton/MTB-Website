# Reporting

## When to use
Produce an evidence-based agent completion report or handoff; use after planning, coding, testing or review.

## Procedure
1. Separate verified observations from assumptions and proposed next steps.
2. List changed files and actual commands with PASS, FAIL or NOT RUN.
3. Report acceptance criteria status, blockers, uncertainty and remaining risks.
4. Use templates/handoff.md when transferring work to another agent.

## Required output
Concise status with revision, evidence, limitations and next owner.

## Stop and escalate when
Missing evidence being mistaken for success.

Follow repository `AGENTS.md`; never claim unexecuted tests passed and never merge/deploy without approval.
